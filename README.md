# 🛵 GEats – Job de livraison immersif pour Garry's Mod RP

GEats transforme le métier de livreur en véritable activité pour vos serveurs de roleplay.

Le joueur dispose d'un **smartphone intégré** avec une **application dédiée** : il se met en ligne, reçoit des demandes de livraison, consulte les informations de la commande, puis l'accepte ou la refuse. Il fait apparaître son scooter, récupère la commande, traverse la map et termine la livraison pour être payé.

> 📱 Ouvrir l'app → 📦 Accepter → 🛵 Rouler → 📍 Livrer → 💵 Encaisser

---

## ✨ Fonctionnalités

### 📱 Téléphone & application
- Smartphone intégré
- Application GEats dédiée avec interface moderne

- Gestion des commandes directement depuis le téléphone

- Demandes de livraison dynamiques
- Acceptation ou refus des commandes

## 🚀 Installation

1. **Téléchargez GEats** depuis la page [Releases](../../releases) de ce dépôt (ou via **Code → Download ZIP**) et extrayez l'addon dans `garrysmod/addons/`.

   L'arborescence doit ressembler à ceci :

   ```
   garrysmod/
   └── addons/
       └── noah_geats/
   ```

   > ⚠️ Il ne doit pas y avoir de dossier supplémentaire entre `addons` et `noah_geats`. Si le dossier s'appelle `GEats-main` après extraction, renommez-le en `noah_geats`.

2. **Installez les dépendances Workshop** (voir [Prérequis](#-prérequis)).
3. **Redémarrez complètement** votre serveur Garry's Mod.
4. **Configurez les points de livraison** (voir ci-dessous).
5. **Ajustez les réglages** dans les fichiers de configuration si besoin.

---

## 📍 Configuration des points de livraison

Les points sont placés directement en jeu avec l'outil GEats :

1. Connectez-vous au serveur en tant qu'administrateur
2. Équipez le **Tool Gun**
3. Sélectionnez l'outil **GEats**
4. Rendez-vous à l'endroit souhaité
5. Placez / configurez le point de livraison
6. Répétez l'opération pour les autres emplacements

Chaque map peut avoir ses propres points : restaurants, commerces, maisons, entreprises, lieux de la ville et autres lieux RP.
